# 🍁🌸 日本櫻花與紅葉即時地圖 (Sakura & Momiji Live Map)

> 專為日本全境打造的即時花況與紅葉進度互動地圖，深度整合 JMA 氣象測站、衛星空照圖資與觀賞適宜度指數。

---

## 🌟 核心特色

1. **四季雙模式切換（🍁 秋季賞楓 / 🌸 春季賞櫻）**
   - 系統依時令動態感知，9～12 月預設進入「秋季賞楓模式」，呈現大雪山、層雲峽、奧入瀨、京都東福寺等 35 處紅葉名所。
   - 亦可一鍵切換至「春季賞櫻模式」，查看目黑川、新宿御苑、弘前城等 34 處賞櫻名所。

2. **清爽日系現代排版（無刺眼閃爍、資訊分明）**
   - 捨棄多餘的背景落葉粒子與光暈閃爍，保留最純粹的高可讀性地圖視野。
   - 左側側邊欄瘦身優化，地圖空間提升 25%，點擊地圖任意空白處即時自動收合抽屜。

3. **強大模糊搜尋與地區/進度過濾**
   - 支援中、日、英名稱、都道府縣、地區、樹種品種（如銀杏、枝垂櫻、水楢）、景點簡介多維度即時檢索。
   - 篩選按鈕文字動態隨季節無縫適配（見頃、滿開、青葉等）。

4. **JMA 日本氣象廳 5km 網格微氣候連線**
   - 提供精確測站經緯度、即時氣溫、體感溫度、相對濕度、即時風速與未來 3 日預測。
   - 內建「今日觀賞適宜度指數（Hanami / Momiji Index）」，輔助遊客評估當日是否適宜戶外賞景與攝影。

5. **高解析圖資切換**
   - 右上角可隨時在「🗺️ 街道地圖 (OSM)」、「🛰️ 高解析衛星空照 (Esri)」與「⛰️ 等高線地形圖」間自由切換。

## 🚀 快速啟動

```bash
# 1. 解壓縮檔案並進入專案目錄
cd Sakura-Map

# 2. 安裝必要套件 (Flask, markupsafe)
pip install -r requirements.txt
pip install markupsafe==2.1.5

# 3. 啟動伺服器
python app.py
```

開啟瀏覽器前往：`http://127.0.0.1:5001` 即可體驗！
